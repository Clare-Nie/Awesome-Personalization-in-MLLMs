# Contributing

Contributions are welcome.

## What to Add

- Papers on personalization in LLMs / MLLMs
- Memory systems for long-term agents
- Personalized alignment methods
- Benchmarks, datasets, and evaluation protocols
- Useful project pages, code repositories, and leaderboards

## Entry Format

Please use this format:

```markdown
- **Paper Title** (Venue / Date)  
  One concise sentence about what the paper contributes.  
  Links: [arXiv](...), [Code](...), [Project](...)
```

## Quality Guidelines

- Prefer papers directly related to personalization, user modeling, long-term memory, or personalized evaluation.
- Keep descriptions factual and concise.
- Avoid adding papers that only mention personalization tangentially.
- If a paper is very new, include the exact month or arXiv date when possible.
